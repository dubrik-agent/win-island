# Бэклог: баги и доработки

Правило работы: пункты закрываются по одному — правка → сборка → проверка живьём
→ отметка `[x]`. Экранные тесты — **только на втором мониторе** (-1920,0, 1280×720,
150 %), основной монитор не занимаем.

## P0 — сломано / мешает пользоваться

- [x] **4. Невидимая поверхность вокруг островка.** Решено оконным регионом
  (`CreateRoundRectRgn` + `SetWindowRgn`): окно физически обрезано по островку + 14 CSS px
  на тень, поэтому клики рядом уходят в приложение под островком (проверено кликом по
  тестовому окну: край → попадание, островок → поглощается). HTTRANSPARENT и
  WS_EX_TRANSPARENT не работают через процессы WebView2.
- [x] **11. Окно настроек белое и пустое.** Причина: страница не успевала отрисоваться,
  а фон окна оставался белым (плюс белый текст ошибки на белом). Теперь у окна
  нативный `background_color` по теме, непрозрачный фон `html/body` до старта JS,
  `prevent_overflow_with_margin` (окно не открывается больше монитора) и видимая
  панель с текстом ошибки вместо пустоты. Проверено на втором мониторе.
- [x] **1. Глобальные хоткеи не работают.** Регистрация на самом деле была успешной
  (проверено: второй процесс получает 1409 «уже занято»), а ошибки молча
  проглатывались `let _ =`. Сделано: `install_hotkeys` с логом по каждому действию,
  `hotkey_status` + событие `island://hotkeys-status`, поле-рекордер в настройках
  (клик → сочетание с модификатором, Esc — отмена), защита от дублей и показ
  «занята другой программой». Перерегистрация сразу после сохранения настроек.
  Показ островка по хоткею больше не крадёт фокус (SW_SHOWNOACTIVATE). Проверено:
  WM_HOTKEY → скрытие/показ, перепривязка Ctrl+Alt+K, конфликт с чужой программой.
- [x] **17. Не работают кнопки «Скрыть островок», «Папка данных», «Выход».**
  Причина была в смешении `WebviewWindow::hide()` (кэш видимости tao) с нативным
  `ShowWindow`: второй `hide()` становился пустышкой. Теперь показ/скрытие идут
  только через Win32 (`show_no_activate` / `hide_window`), watcher тоже.
  `open_data_dir` логирует результат. Проверено настоящей мышью на втором
  мониторе: скрыть (3 цикла скрыть/показать), папка данных (открылся Explorer),
  выход (процесс завершился).
- [x] **8. Автоскрытие не работает.** Причина: интервал 1.5 с вызывал
  `scheduleAutoHide()` безусловно и сбрасывал таймер раньше срабатывания — при
  любой задержке > 1.5 с островок не скрывался никогда. Теперь таймер
  перезапускается только по событиям (ввод, смена настроек, сворачивание), а
  интервал лишь «доcтавляет» его, если он не заведён. Проверено: задержка 3 с →
  скрытие через 3 с, наведение удерживает островок, уход снова скрывает,
  хоткей возвращает.
- [x] **7. Настройки позиции (смещение по горизонтали, отступ сверху) не работают.**
  Сама математика в Rust была верной (`x = центр монитора + offsetX·scale`,
  `y = workArea.y + topOffset·scale`), но ползунок был непригоден: он двигал окно
  под курсором, из-за чего значение «убегало» в максимум (проверено: −300 → 600
  за один жест), окно уезжало, панель схлопывалась. Теперь позиция применяется
  по отпусканию ползунка, а панель на время жеста закреплена (`bridge.hold`).
  Проверено мышью: −275 px и 23 px применяются и сохраняются в JSON.
- [x] **9. Отключение виджета перекидывает вкладку и сбрасывает прокрутку настроек.**
  `rebuild()` всегда обнулял активную вкладку и вызывал `setActive` заново, а
  `onShow` виджета настроек сбрасывает скролл в 0. Теперь активный виджет
  перезапускается только если его действительно отключили/удалили; в остальных
  случаях подсветка вкладки просто перерисовывается. Таб-бар при пересборке
  сохраняет клавиатурный фокус и остаётся центрированным. Проверено: скролл
  420→420 при включении и 330→330 при отключении, активная вкладка не меняется.

## P1 — работает, но некрасиво/непонятно

  панель со скруглением) и подпись с текущими размерами; обновляется по подписке на
  настройки, поэтому виден прямо во время перетаскивания ползунка. У самого островка

- [x] **6. Тень у раскрытой панели: сильная, с острыми углами.** Многослойная мягкая

  Заодно тосты переехали внутрь панели, чтобы регион их не срезал.
- [x] **23. Календарь не влезает/выглядит сырым.** Сетка пересобрана под ширину панели
  (ячейки-плитки 28 px, состояния «сегодня/выбрано/выходной/вне месяца/есть планы»

  на текущем месяце), строка плана — чекбокс + время + текст, время стало обычным
  текстовым полем с нормализацией (`9`, `930`, `09:30`), потому что нативный
  `input[type=time]` рисовал белый системный попап поверх тёмной панели. Пустой день —
  одна строка слева, а не «дырка». Проверено мышью: выбор даты, «Сегодня», листание
  месяцев, добавление/удаление/отметка плана, правка времени (09:35), ширина 340 и
  масштаб 1.3.
- [x] **24. Масштаб панели.** `transform: scale()` уменьшал только картинку, а раскладка
  оставалась прежней: при 80 % панель обрезалась справа, при 130 % вылезала за рабочую
  область. Теперь окно считается как `max(1, scale) × ширина` (раскладка не сжимается
  флексом), высота панели ограничена рабочим столом с учётом масштаба (`--panel-max`),
  лишнее прокручивается внутри панели, вкладки сжимаются под узкую панель (минимум
  22 px), смена масштаба/ширины/экрана пересчитывает открытую панель на месте.
  Проверено на 0.8 и 1.3 (календарь и настройки): панель целиком в экране, ничего не
  обрезано, окно не перекрывает клики.
- [x] **10. Настройки: красота и структура.** Список переехал на карточки-аккордеоны
  (`section()`): заголовок, подпись с текущим значением, шеврон, плавное раскрытие
  через `grid-template-rows`; 10 групп вместо простыни, единые контролы, подсказки
  под блоками, отдельное окно настроек 880×1020 рисуется целиком (проверено на
  втором мониторе).
- [x] **3. Скрывать неактуальные настройки.** Правила: прозрачность только у темы
  «Стекло» (тёмная и светлая теперь непрозрачные — текст на просвечивающей белой панели
  не читался), скорость анимации — только при включённых анимациях, задержка наведения

- [x] **2. «Что здесь можно» сворачивается.** Все группы настроек стали аккордеонами
  (карточки с шевроном), «Что здесь можно» по умолчанию свёрнуто, состояние каждой

- [x] **18. Калькулятор: копировать ответ.** Кнопка с иконкой в правом углу дисплея,

## P2 — новые возможности

- [x] **13. Кнопка «По умолчанию»** — двухшаговая (первый клик взводит «Точно
  сбросить?» на 4 с, второй сбрасывает) в разделе «Данные и приложение»; патчит
  `DEFAULT_SETTINGS`, сохраняет через стор и перестраивает список. Проверено:
  тема/акцент/ширина/смещение/хоткеи вернулись к заводским.
- [x] **14. Кнопка «Центрировать»** — в «Положении», ставит `offsetX: 0` и сразу
  двигает окно; проверено: полоска встала ровно по центру монитора (−1130 px при
  ширине окна 339 px на экране −1920…0).
- [x] **15. Две новые темы.** «Полночь» — глубокий индиго-фон `#0b0d16`, холодный
  текст `#eef1fb` (контраст ≈16:1), синеватые границы и мягкое свечение сверху;
  «Песок» — тёплая бумага `#f3eee4`, чернильный текст `#241e16` (≈13:1), тёплые
  границы и тени. Обе темы непрозрачные, работают и в островке, и в отдельном окне
  настроек (нативное окно сразу красится в цвет темы, без белой вспышки). Светлые
  темы используют общий набор «чернильных» оверрайдов через `data-tone="light"`.
  Проверено визуально на втором мониторе.
- [x] **16. Порядок виджетов.** В «Виджетах» каждая строка теперь перетаскивается
  (за ручку слева, с живой перестановкой при наведении) и имеет кнопки ↑/↓ для
  тех, кто предпочитает клики; порядок сохраняется в `data/store/widgets.json`
  (`order`), переживает перезапуск и синхронизируется между островком и отдельным
  окном настроек (событие `island://widgets-changed` теперь несёт и `order`).
  Проверено: стрелки и синтетический drag меняют вкладки и файл, после reload
  порядок сохраняется.
- [x] **19. Drag & drop файла на свёрнутый островок.** При входе курсора с файлами
  (`tauri://drag-enter`) островок раскрывается сразу на «Полке» и подсвечивает
  зону приёма пунктиром (`shelf.dropping`); при отпускании файлы уходят на полку,
  всплывает «Файл добавлен на полку», панель сворачивается через 1.6 с, если курсор
  не над ней; уход курсора снимает подсветку. Проверено синтетическими
  `tauri://drag-*` событиями: панель раскрылась на shelf, файл попал в
  `data/store/shelf.json`, тост появился.
- [x] **20. Таймер: ручное время и кнопки ±шага.** Цифры в кольце — настоящий
  `<input>`: `25` = минуты, `5:30` = мин:сек, `1:02:03` = ч:м:с (потолок 99 ч),
  Enter применяет, Esc отменяет, мусор откатывается к прежнему времени. Слева и
  справа от пресетов — кнопки `−`/`+` по минуте, с Shift — по пять; пресеты с
  Shift тоже вычитают. «Старт/Пауза/Продолжить» и «Сброс» стоят над кольцом,
  подсказка под кнопками. Проверено: ввод 5:30 → 5:30, «+» → 6:30, Shift+«−» → 1:30,
  «−» → 1:00, пресет 25 → 25:00, старт тикает (24:59), пауза → «Продолжить»,
  сброс → 25:00, «abc» не принимается.
- [x] **21. Заметки: обычный текст.** Над списком появился переключатель
  «Список / Текст» (сегмент-контрол, состояние хранится в `data/store/notes.json`
  как `mode`). В текстовом режиме — одно большое поле на всю заметку, без галочек
  и кнопки «+ Новый пункт», счётчик показывает «N строк». Переключение переносит
  содержимое: список → текст склеивается по строкам, текст → список разбивается
  на пункты, галочки сохраняются по совпадению текста; пустые строки-абзацы в
  списке отбрасываются. Проверено: 2 пункта (один отмечен) → текст «Купить
  молоко\\nПозвонить маме», правка до 5 строк → назад в список 5 пунктов, галочка
  на месте, режим переживает reload.
- [x] **22. Исключения для автоскрытия.** В «Поведении» появился блок «Не скрывать
  при»: поле со списком процессов через запятую (регистр и `.exe` не важны) и
  кнопка «Текущее окно», которая сама подставляет приложение с переднего плана и
  показывает тост. Список хранится в `autoHideExceptions` и проверяется в двух
  местах: нативный вотчер (`foreground_app()` → имя процесса через
  `QueryFullProcessImageNameW`) не прячет островок в полноэкранном/максимизированном
  окне из списка, а idle-автоскрытие перед скрытием спрашивает тот же процесс.
  Проверено на живом полноэкранном приложении `pioneergame`: с исключением
  `visible=True`, без него `visible=False`, после выключения «скрывать в
  полноэкранных» снова `True`; idle-автоскрытие 3 с тоже уважает исключение;
  нормализация « OBS64.exe , vlc ,, obs64 » → `obs64, vlc`.
- [x] **12. Медиа: все звуковые сессии.** Под плеером — список источников: имя
  приложения, трек, своя кнопка паузы/играть для каждой сессии (не задевая
  остальные) и выбор, что показывают большие кнопки и перемотка. Ниже — громкость
  выбранного приложения из микшера Windows: иконка мьюта, ползунок и проценты.
  Rust: `media_control_source`, `media_volume`, `media_set_volume`,
  `media_set_mute`; новый `audio.rs` на Core Audio (`IAudioSessionManager2`,
  `ISimpleAudioVolume`, `IAudioMeterInformation`), матчинг по имени процесса из
  AUMID, для непрозрачных AUMID Chromium — самая громкая сессия. Проверено:
  громкость своей сессии 100 → 35 → мьют → 100, чужое имя даёт `null` (не трогает
  чужой звук); интерфейс на тестовом снимке из трёх источников — пауза Edge не
  трогает Spotify, выбор VLC, ползунок 30 % и мьют дают нужные вызовы; пустое
  состояние снова сжимает панель.
- [x] **1b. Хоткеи: переназначение.** В «Горячих клавишах» каждое действие — поле
  `Ctrl+Alt+Space`, по клику записывает следующее нажатие (Esc отменяет). Нужен
  модификатор, дубликат внутри приложения отклоняется с подсказкой, занятое другой
  программой сочетание показывает «занята другой программой» и **возвращает
  прежнюю рабочую комбинацию** (тост «Сочетание занято — оставил …»), чтобы не
  остаться без хоткея. Rust перерегистрирует все три сразу, старые освобождаются,
  статус каждого отдаётся в UI (`hotkey_status`). Проверено: `Ctrl+Alt+J`
  записался (внешний пробник: J — `TAKEN 1409`, прежний Space — `FREE`), дубликат
  `Ctrl+Alt+H` отклонён, голое `K` требует модификатор, Esc снимает запись,
  занятый `Ctrl+Alt+K` вернул `Ctrl+Alt+Space` со статусом `null` и тостом.

## P3 — качество (мои добавки)

- [x] **25. Белая вспышка при старте** любого окна: тема в `index.html` до JS,
  фон окна в Rust совпадает с темой.
  Проверено: `html`/`body` прозрачные (`rgba(0, 0, 0, 0)`), видимую поверхность
  рисует нативное окно — `theme_surface()` в Rust даёт `rgb(9, 9, 11)` для
  `dark`, `surfaceFor()` во фронтенде — то же значение; `localStorage`
  `wi.theme`/`wi.accent` применяются inline-скриптом до первого кадра.
  Окно настроек: `documentElement.style.background` ставится первой строкой
  `bootstrapSettingsWindow`, `background_color` у билдера совпадает с темой.
  Отдельно исправлено: окно настроек создаётся **в рабочем потоке** — из
  главного потока WebView2 оставался на `about:blank`, и пользователь видел
  пустое тёмное окно (`[settings] window created` в логе, затем страница
  рисуется). Закрытие окна («Готово» или крестик) теперь прячет его
  (`prevent_close` + `hide`), поэтому повторное открытие показывает уже
  отрисованную страницу, а не пустой кадр.
- [x] **26. Производительность:** не дёргать `setBounds`/`setHitRect` чаще, чем нужно;
  дебаунс ресайза; проверить, что свёрнутый островок не крутит rAF.
  Замер на живом окне: серия из 10 `resize` за 100 мс → 1 `setBounds` +
  1 `setHitRect`; развёрнутый простой 2 с → 0 вызовов, 0 кадров rAF;
  свёрнутый простой 2 с → 0 вызовов, 0 кадров; 4 переключения вкладок
  (высота панели меняется анимированно) → 6 `setBounds` + 13 `setHitRect`.
  Прогресс-бар медиа крутит кадры только когда виджет виден и трек играет.
- [x] **27. Клавиатура.** Вкладки — настоящий `role="tab"` с roving `tabindex`
  (в Tab-порядке только активная): `←`/`→` водят по ленте и сразу переключают
  виджет, `Home`/`End` — к краям, `Enter`/`Space` работают нативно, `aria-selected`
  и `aria-label` на месте. Фокус-кольцо `:focus-visible` цветом акцента (через
  `:where()`, чтобы виджеты могли перекрывать). `Esc` теперь сначала отдаётся
  тому, что открыто: обработчик проверяет `event.defaultPrevented` (таймер,
  запись хоткея) и новый стек слоёв `src/core/escape.ts` — `pushEscapeLayer()`
  для будущих поповеров; островок сворачивается, только если никто не взял
  клавишу. Проверено настоящими клавишами через CDP `Input.dispatchKeyEvent`:
  Tab с пилюли → активная вкладка, `→` → «Система», `←` → «Таймер», второй Tab

- [x] **48. Таймер: ввод игнорировался, а фокус сбрасывал паузу.** Цифры
