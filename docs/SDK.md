# SDK виджетов (черновик v0.1)

Виджет — это модуль TypeScript, который получает DOM-контейнер и ограниченный
контекст. Он не имеет доступа к файловой системе, процессам и сети: только к
`ctx`, который даёт ядро. Это тот самый контракт, по которому новые виджеты
генерируются и подключаются.

## Определение виджета

```ts
import type { WidgetDef } from "../core/widget-types";

export const myWidget: WidgetDef = {
  id: "my-widget",        // уникальный, латиница/дефис
  name: "Мой виджет",     // подпись в вкладках
  icon: `<svg ...></svg>`,// встроенная SVG-иконка 24×24, stroke=currentColor
  defaultEnabled: true,   // включён по умолчанию
  miniPriority: 40,       // меньше = важнее; в пилюлю попадают два первых
  mount(root, ctx) {
    // root — пустой div, уже вставленный в панель
    root.append(/* ваш DOM */);

    // необязательные хуки жизненного цикла
    return {
      onShow() {},   // виджет стал активной вкладкой
      onHide() {},   // пользователь ушёл на другую вкладку
      unmount() {},  // виджет выключили в настройках
    };
  },
};
```

## Контекст `ctx`

| Метод | Назначение |
|---|---|
| `ctx.settings.value` | текущие настройки (только чтение, меняйте через `patch`) |
| `ctx.settings.patch({...})` | изменить настройки (сохраняются автоматически) |
| `ctx.toast("текст")` | короткое сообщение внизу панели |
| `ctx.setMini(node \| null)` | компактный индикатор в свёрнутой пилюле |
| `ctx.expand()` / `ctx.collapse()` | управлять раскрытием |
| `ctx.requestResize()` | пересчитать высоту панели после изменения контента |
| `ctx.chime()` | мягкий звук уведомления (без файлов) |
| `ctx.alarm({ id, text, time? })` | полноценное напоминание: баннер над вкладками, звук из настроек и повтор, пока пользователь не нажмёт «Остановить» |

`ctx.alarm` — то, что стоит использовать для событий, которые нельзя пропустить.
Баннер живёт вне виджета: переключение вкладки или сворачивание панели его не
убирают. Если в настройках выключен режим «звук не замолкает», сигнал звучит один
раз, а панель не удерживается.

Пилюля узкая: в ней помещаются часы и максимум два мини-индикатора. Третий и
последующие скрываются, поэтому `setMini` стоит использовать для самого важного.
Порядок задаёт `miniPriority` (медиа — 0, полка — 5, таймер — 10; по умолчанию 50).
В режиме «линия» мини-индикаторы не показываются — только полоска.

## Правила производительности

1. **Ничего не тикает вхолостую.** Таймеры запускайте в `onShow`, останавливайте в
   `onHide`/`unmount`.
2. **Не опрашивайте систему чаще, чем раз в секунду.** Системный монитор делает
   это раз в 1.5 с и только когда виджет активен.
3. **Не создавайте DOM в цикле анимации.** Меняйте текст/классы/`style`.
4. **Тяжёлые вычисления** — не в главном потоке; выносите в Rust-команды.
5. **Высота**: после изменения количества элементов вызывайте `ctx.requestResize()`.

## Клавиатура и `Esc`

- Интерактивные элементы делайте настоящими `<button>`/`<input>`: они получают
  `Enter`/`Space` и попадают в `Tab`-порядок без ручной работы.
- Не рисуйте фокус сами: в стилях есть общее кольцо `:focus-visible`. Если нужен
  свой вид, перекройте `outline` у конкретного элемента.
- Если виджет открывает поповер или режим редактирования, зарегистрируйте слой,
  чтобы `Esc` закрыл именно его, а не свернул островок:

  ```ts
  import { pushEscapeLayer } from "../core/escape";

  const release = pushEscapeLayer(() => {
    closePopover();
    return true; // клавиша обработана, островок остаётся открытым
  });
  // при закрытии: release()
  ```

- Собственный обработчик `keydown` на `Esc` может просто вызвать
  `event.preventDefault()` — ядро уважает `defaultPrevented`.

## Хранение данных

Используйте `api.readStore<T>(name)` / `api.writeStore(name, value)`.
Имя — только `[a-zA-Z0-9_-]`, файл кладётся в `data/store/<name>.json`.
Общий код виджета не имеет прямого доступа к диску.

## Внешние (пользовательские) виджеты — план

Экспериментальный режим (в настройках) загрузит виджеты из папки:

```
widgets/<id>/
  manifest.json   { "id": "...", "name": "...", "icon": "...", "entry": "index.js" }
  index.js        ES-модуль, экспортирует WidgetDef
```

Каждый виджет будет рендериться в sandboxed iframe и общаться с ядром через
`postMessage` — чтобы сторонний код не мог сломать островок или получить доступ
к системе. Контракт тот же, что у встроенных виджетов.

## Как добавить встроенный виджет

1. Создайте `src/widgets/my-widget.ts` по образцу выше.
2. Добавьте его в массив `widgetDefs` в `src/widgets/index.ts`.
3. Перезапустите `npm run tauri dev` (горячая перезагрузка виджетов — в плане).
